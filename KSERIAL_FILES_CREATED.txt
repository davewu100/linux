KERNEL INTEGRATION
==================

To integrate into kernel build:

1. Files are already in correct locations:
   - include/linux/kserial.h
   - kernel/kserial.c
   - kernel/kserial_procfs.c

2. Add to kernel/Makefile:
   obj-$(CONFIG_KSERIAL) += kserial.o
   obj-$(CONFIG_KSERIAL) += kserial_procfs.o

3. Add Kconfig entry:
   config KSERIAL
       bool "k-serial: BTF-based field subscription"
       depends on DEBUG_INFO_BTF
       help
         Enable k-serial for dynamic field subscription

4. Build kernel with:
   CONFIG_DEBUG_INFO_BTF=y
   CONFIG_KSERIAL=y
